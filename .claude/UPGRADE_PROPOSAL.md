## 3. 我提议在原规划之上加入的方向

按「视觉冲击 × 工程成本 × 风险」三维排序，从高 ROI 到低。

### 3.1 ⭐ 3D 重构走 Gaussian Splatting + SuperSplat（替换原规划的「方法不限」）

**论据**：
- 转盘视频生成 3D：照片测量法（COLMAP / Meshroom）和 3DGS 都可行，但是 **3DGS 视觉震撼明显高一档**，splat 看起来「像真的」，而 mesh 看起来「像 3D 模型」。
- 工具链：[Nerfstudio splatfacto](https://learnopencv.com/3d-gaussian-splatting/)（训练 20-30 min on RTX 3060）+ [SuperSplat](https://blog.playcanvas.com/publish-your-gaussian-splats-with-supersplat/)（浏览器内清理 + 一键导出可独立运行的 HTML viewer，含 orbit controls 与 WebXR，MIT 许可）。
- 风险：CUDA + PyTorch 环境配置可能出问题；不锈钢焊件高光对 SfM 特征匹配不友好。建议第 1 天做 2 小时小样本试跑再决定全力推。

**演示策略**：
- 主方案：3DGS splat 在前端 Three.js 嵌入展示（或直接 iframe 嵌入 SuperSplat 导出的 HTML）。
- 备用方案：Meshroom 跑一份 `.glb` mesh 作为「保底兜底」，离线能用。
- 两份资产同源：用同一组 60-100 张转盘照片喂两条管线。

**前端落地点**：新增 `front/components/modules/ThreeDModule.tsx`（左侧导航新建「3D 重构」），静态资产放 `front/public/3d/sample-weld/`。

**预算**：1 天采集+处理，1 天集成。

### 3.2 语音播报（TTS）

**论据**：
- Web Speech API `speechSynthesis` 在 Chrome 33+、Edge 79+ 支持；Windows 11 + Edge 可以用「Microsoft Xiaoxiao Online」之类的神经语音，质量接近商用 TTS。
- **但带「Online」的语音离线不可用**。本地兜底如「Microsoft Huihui Desktop」音质较差但可用。
- 离线兜底需要预装 zh-CN 语音包，并在代码里显式按名字选 voice，不要依赖默认。
- 最稳：预录关键播报为 MP3 备用。

**演示价值**：
- 评委现场听到「检测到 2 处气孔，建议降低焊接电流」会留下印象。
- 是几乎免费的「智能化」感观加成。

**落地**：`front/lib/tts.ts` 封装 `speechSynthesis`，detection 模块在分数变化超过阈值时播报；提供静音开关。**预算 0.5 天**。

### 3.3 单次检测实时分数曲线

**论据**：现在前端只有「历史趋势 + 预测」的长期曲线，**没有「这次焊接过程中」的实时分数曲线**。把 inference_loop 拿到的每一帧分数（每秒 6 次）画成滚动 mini-chart，是几乎零成本的演示加成，且能让评委直观看到「检测系统在持续运转，不是单次截图」。

**落地**：detection 模块加 recharts mini-line-chart，订阅现有的 `YOLO_DATA` 轮询返回。**预算 0.5 天**。

### 3.4 「教学模式 vs 严格模式」阈值切换

**论据**（来自评委常见质疑研究，§4）：判断系统的 FP/FN 权衡是评委最容易追问的事情。**与其防御，不如做成功能**：在 detection 页面 UI 上加一个二档开关：
- 教学模式：低置信度阈值（0.3），鼓励发现潜在缺陷
- 严格模式：高置信度阈值（0.6），仅报告高置信缺陷

这把「YOLO 默认 0.3 太低」的扣分点转成「我们有可配置策略」的加分点。后端把 confidence_threshold 做成 detection runtime 的可写状态即可。**预算 0.5 天**。

### 3.5 国家标准对齐叙事

**论据**（已研究并核对）：
- **GB/T 19418-2003** 《钢的弧焊接头 缺陷质量分级指南》（对应 ISO 5817），直接定义弧焊缺陷分类等级 → 我们的评分体系可以对齐其「优秀/良好/合格/需改进」分档。
- **GB/T 32259-2015** 《焊缝无损检测 熔焊接头目视检测》→ 直接对应「基于摄像头的目视检测」叙事。
- **1+X 特殊焊接技术职业技能等级证书** → 把系统定位为「面向 1+X 证书认证的教学辅助平台」，强化教学价值。

**落地**：
- README 加一段「标准对齐」描述。
- 报告 PDF 加一行「评分参考 GB/T 19418-2003 缺陷分级」。
- 演示讲稿里穿插「我们的分数区间映射到 GB/T 19418 的 B 级/C 级缺陷」。

**注意**：不要伪造「通过 GB/T 标准认证」之类的说法——只说「评分参考/对齐」。**预算 0.5 天**（主要是改文案 + PDF 模板）。

### 3.6 一键演示降级模式

**论据**：现场失败概率最高的环节是摄像头、AI、网络。

**实现**：
- 在「关于我们/设置」页面加一个「演示安全模式」开关，开启后：
  - 摄像头改为读取 `front/public/demo/weld.mp4`
  - YOLO 检测改为读取一份预测结果 JSON 而非实时跑
  - AI 教师返回本地规则建议（已实现）
  - PDF 用本地缓存（已基本实现）
- 开关存 localStorage，方便现场快速切换。

**预算 1 天**。这一条是「保命」选项，建议不削减。

### 3.7 演示数据预播种

**论据**：数据库当前 `welding.db` 已经有内容（commit 3df9e9e 入仓的真实数据），但 PK / 预测图表的「丰满度」依赖于多学生 × 多批次数据。如果只有 30 条同一个学生的记录，PK 看起来很空。

**实现**：写一个 `backend/scripts/seed_demo_data.py`：
- 预设 3-4 个演示学生（`student_a` 张三、`student_b` 李四、`student_c` 王五、`teacher_demo`）
- 每个学生生成 15-30 条历史检测记录，分数曲线合理（有上升、有波动）
- 不同学生有不同短板（A 偏宽度差、B 偏缺陷多），方便讲 PK 故事

**预算 0.5 天**。配合演示登录用。

### 3.8 检测结果空间标注 / 缺陷热图

**论据**：现在前端只在视频流上画 bbox。但**保存检测时没有保留 bbox 坐标**。如果保存的时候也存 bbox 坐标（数据库加一列 `defect_bboxes` JSON），就可以在历史记录里点击某条数据，看到「当时缺陷在焊缝什么位置」+ 批次累积的缺陷热图。

**预算 1 天**。需要改数据库（加列，非破坏性），后端 save_score 多存一字段，前端历史记录页面加可视化。

**取舍**：评委追问历史可视化时这一条是杀器；不追问的话作用一般。建议作为 P2，依据时间余裕决定。

### 3.9 国际化轻量化（中英切换）

**论据**：国赛现场偶尔有外籍评审或英文海报需求。**就左侧导航 + 标题这种「外壳文案」做中英切换**，不做正文。

**预算 0.5 天**。可不做，留待最后余力。

## 4. 风险防御 / 减少扣分

来自评委常见质疑研究：

### 4.1 数据集偏倚 / 泛化问题

**评委可能问**：「你这个模型在你训练数据外的焊件上还有效吗？」

**防御**：
- 在「关于我们」页内嵌一张混淆矩阵截图 + 各类 P/R/F1（用现有数据出一次报告即可，**不用重训**）
- 准备 2 张「故意 OOD」的样本（例如不同光照、不同金属），现场展示模型能识别 low confidence
- 已经做的 confidence 阈值滑块就是这一防御的可视化（§3.4）

### 4.2 光照鲁棒性

**评委可能问**：「车间光照变了你怎么办？」

**防御**：
- 准备 1 段「鲁棒性演示」短脚本：对同一张图做亮度/对比度/gamma 调整，展示检测结果稳定
- 在演示讲稿里提一句「训练数据包含光照增强」（如果实际没做，不要说；如果做了，要强调）

### 4.3 FP / FN 成本

**评委可能问**：「漏判和误判哪个成本高？」

**防御**：教学模式/严格模式切换（§3.4）+ 在 PDF 报告里写明白「教学场景下倾向于发现潜在缺陷，故置信度阈值偏低」。把权衡说透。

### 4.4 「数字焊枪」mock 风险

**评委必问**：「这个雷达图是真数据吗？」当前 `/predict/ai-radar-data` 是 7 套 mock 轮换。

**两种处理**：
- 方案 A（推荐）：删 mock，改从真实库聚合，**没数据就少几个维度**，但是真的
- 方案 B（妥协）：保留 mock，但在前端文案明确写「示例数据 - 待接入数字焊枪」，并准备好答辩话术「数字焊枪是系统的扩展点，当前展示的是该接入位的数据样式」

我建议**方案 A**——评委一旦觉得是 fake，整个项目可信度都会掉。**预算 1 天**。
