水平环形导轨 · 3D 高斯泼溅 (3DGS) 焊缝建模

方案：建模相机挂在水平圆环导轨的滑块下方，沿环绕焊缝走一圈拍 100 张俯角图。单台相机 + 360° 视点覆盖，比双侧弧方案少一台相机，又能拍到焊缝顶部和各侧。

高度错位避让：平面检测相机在 Y=280mm 焊缝正上方俯视；环在 Y=170mm 水平面。两者高度差 110mm。平面相机的视线**从环的中心空洞穿过去**，不被环挡。

几何参数：
• 环半径 R = 115mm，相机到焊缝 ≈ 190mm
• 相机俯角 ≈ 53°，斜射焊缝顶面 + 侧面
• 沿环每 3.6° 一帧，一圈 100 张
• 环周长 723mm 分 4 段，单段 ≤ 180mm 桌面打印机出

3DGS 优势：视点空间是 1D 圆环（不是 1D 弧），方位角覆盖完整 360°。SfM 拿到 100 张闭环图，环路 loop closure 约束让位姿解算特别稳。3DGS 训练后焊缝任意角度都能渲染。

硬件特性确认：MF500 卷帘快门 + 30fps + USB 2.0 完全够 3DGS。卷帘只影响动态拍摄，环上每个位置停 ≥100ms 拍单张即可。真正要锁的是自动对焦（不然焦距漂移→内参变化→SfM 失败）。
